# Development

## Setup

### 1. Install [Go](https://go.dev/dl/)

### 2. Install [scoop](https://scoop.sh/) for Windows

### 3. Install make

- For Windows
    ```Powershell
    scoop install make
    ```

- For Linux
    ```Bash
    sudo apt-get install make
    ```

- For Mac
    ```Bash
    brew install make
    ```

### 5. Install [Buf CLI](https://buf.build/docs/installation/)
