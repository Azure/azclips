# Support

Cirrus is currently in preview. Support is provided on a best-effort basis by the maintainers while the project is under active development.

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Please search the existing issues before filing new issues to avoid duplicates. For new issues, file your bug or feature request as a new Issue.

For help and questions about using this project, use GitHub Issues unless your report contains security-sensitive information.

When opening an issue, include:

- What you were trying to do
- The command or workflow you ran
- The expected behavior
- The actual behavior
- Relevant environment details, such as OS, shell, .NET SDK version, and Cirrus version or commit
- Sanitized logs or error messages when useful

Do not include secrets, access tokens, customer data, tenant identifiers, subscription identifiers, or internal-only information in public issues.

## Preview Support Expectations

During preview, maintainers prioritize:

- Security and compliance issues
- Build, test, and installation problems that block evaluation
- Regressions in documented quick-start workflows
- Feedback that improves the public release readiness of the project

Preview support does not include production service-level agreements, guaranteed response times, or custom implementation support.

## Microsoft Support Policy

Support for Cirrus is limited to the resources listed above.

## Security Reports

Do not report security vulnerabilities through public GitHub issues. Follow the repository's security policy for security reporting guidance.
