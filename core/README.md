# Azure CLI v3 Core

This is the core for Azure CLI v3. Which has the following features:

- [] Manage modules
    - [] Load and communicate with modules
    - [] Download, upgrade and remove plugin modules
- [] Route the command to the correct module
- [] Parse and format the command input
- [] Manage and format the command output
- [] Provide and manage the running context
    - [] Provide authentication
    - [] Provide configuration
- [] Provide logging
- [] Provide telemetry
