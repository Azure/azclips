# AzCLIPS user scenarios

Explore end-to-end journeys with AzCLIPS CLI and PowerShell. Each guide includes a user goal, command paths for Bash, PowerShell and the AzCLIPS PowerShell modules where they apply, and cleanup.

## Table of contents

| Scenario | Guide | User outcome |
|---|---|---|
| 1 | [Set up AzCLIPS and move between work environments](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-1-get-started-and-profiles.md) | Install alongside existing tools, check extensions, switch between the classic and preview tools, and switch between named sign-in profiles. |
| 2 | [Deploy an application on a VM and keep it running](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-2-vm-application.md) | Deploy an application, verify it across a VM stop and start, and remove the test environment. |
| 3 | [Give an application secure access to Azure resources](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-3-secure-application-access.md) | Use a managed identity to read a Key Vault secret, then verify access is revoked. |
| 4 | [Deploy and troubleshoot infrastructure as code](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-4-infrastructure-deployment.md) | Preview and deploy a template, investigate a controlled failure and clean up resources. |
| 5 | [Look up identities and register an application in Microsoft Entra ID](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-5-entra-identities-and-applications.md) | Find users, groups and members, register an application and remove the registration. |
| 6 | [Run repeatable deployments from a pipeline](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-6-pipeline-deployments.md) | Sign in without a browser, deploy from a pipeline, detect failures and clean up. |
| 7 | [Find the right command, or call REST when there isn't one](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-7-find-commands-and-rest.md) | Find commands with help and tab completion, and create a resource with a REST request when there isn't a dedicated command. |
| 8 | [Recover from a failed command with AI troubleshooting](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-8-ai-troubleshooting.md) | Recover from a controlled failure with AI troubleshooting, started manually or automatically, in one-shot or interactive style. |
