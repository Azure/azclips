# AzCLIPS user scenarios

Explore end-to-end journeys with AzCLIPS CLI and PowerShell. Each guide includes a user goal, command paths for Bash, PowerShell and the AzCLIPS PowerShell modules, and cleanup.

## Table of contents

| Scenario | Guide | User outcome |
|---|---|---|
| 1 | [Set up AzCLIPS and move between work environments](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-1-get-started-and-profiles.md) | Install alongside existing tools and switch between named sign-in profiles. |
| 2 | [Deploy an application on a VM and keep it running](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-2-vm-application.md) | Deploy a web application, verify it across a VM stop and start, and remove the test environment. |
| 3 | [Give an application secure access to Azure resources](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-3-secure-application-access.md) | Use a managed identity to read a Key Vault secret, then verify access is revoked. |
| 4 | [Deploy and troubleshoot infrastructure as code](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-4-infrastructure-deployment.md) | Preview and deploy a template, investigate a controlled failure and clean up resources. |
| 5 | [Store and retrieve application data](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-5-application-data.md) | Upload and retrieve blob and file-share data, verify its contents and remove test resources. |
| 6 | [Look up identities and register an application in Microsoft Entra ID](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-6-entra-identities-and-applications.md) | Find users, groups and members, register an application and remove the registration. |
| 7 | [Run repeatable deployments from a pipeline](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-7-pipeline-deployments.md) | Sign in without a browser, deploy from a pipeline, detect failures and clean up. |
| 8 | [Complete a task when a command is missing or fails](https://github.com/Azure/azclips/blob/docs/scenario-2-feedback/docs/scenario-8-missing-command-and-recovery.md) | Discover commands, use REST, recover from a failure with AI troubleshooting and add an extension. |
