# How to Refresh the Wiki

The wiki under `wiki` is generated from the source files and documents in this repository locally by deep-wiki. To refresh the wiki, you can follow these steps:

## Prerequisites

1. `agency`: https://eng.ms/docs/coreai/devdiv/one-engineering-system-1es/1es-jacekcz/startrightgitops/agency
2. The `deep-wiki` plugin: https://vigilant-adventure-v9qpqwn.pages.github.io/playground/#plugins/deep-wiki?q=wiki

## Steps to Refresh the Wiki
1. Run `agency copilot`
2. Run `/deep-wiki:generate` command
3. Run the `wiki:preview` task in VS Code to preview the wiki locally
