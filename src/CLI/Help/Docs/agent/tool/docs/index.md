Description: The `az agent tool docs` command group provides local command metadata for the Agent and external AI tools. Use `list` to list discoverable commands, `show --name` to return one command's metadata, or `generate` to rebuild the catalog from the current extension set. The group itself is not executable.

### Discover agent tool docs commands

```bash
az agent tool docs --help
```
