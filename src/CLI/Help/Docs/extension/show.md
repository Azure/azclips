Description: Display metadata for a single installed extension, including its package id, installed version, source feed, pin status, and the CLI verbs it contributes.

### Show by verb

```bash
azv2 extension show --name compute
```

### Show by package id

```bash
azv2 extension show --name Microsoft.Azure.Cirrus.Extensions.Compute
```
