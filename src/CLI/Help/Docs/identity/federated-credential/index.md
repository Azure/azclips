Description: Create, list, inspect, update, and delete federated identity credentials that trust an external identity provider (OIDC issuer), allowing a workload to exchange an external token for a Microsoft Entra access token without a secret or certificate.

### Discover federated credential commands

```bash
az identity federated-credential --help
```
