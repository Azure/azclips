Description: Manage Azure networking resources. Currently exposes virtual network (VNet) and subnet lifecycle management under `az network vnet`, network security group (NSG) lifecycle management under `az network nsg`, public IP address lifecycle management under `az network public-ip` and network interface lifecycle management under `az network nic`.

### Discover network commands

```bash
az network --help
```
