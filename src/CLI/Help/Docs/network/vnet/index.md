Description: Create, inspect, list, and delete Azure virtual networks (VNets). A virtual network is the fundamental building block for private networking in Azure; `az network vnet create` provisions the VNet address space together with its subnets in a single call.

### Discover vnet commands

```bash
az network vnet --help
```
