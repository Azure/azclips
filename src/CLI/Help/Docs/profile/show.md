Description: Show the full details of a saved profile by name, or show the currently active profile when no profile name is provided. Specify either a profile name or --active, not both.

### Show a profile by name

```bash
az profile show production
```

### Show the active profile

```bash
az profile show
```

### Show the active profile explicitly

```bash
az profile show --active
```
