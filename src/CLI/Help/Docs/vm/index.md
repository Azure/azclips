Description: Create, inspect, list, start, stop, and delete Azure virtual machines. The `vm create` command provisions a virtual machine plus its supporting network interface, virtual network, and network security group in a single call. `vm stop` powers a machine off but leaves it allocated and billed; `vm deallocate` releases its compute resources.

### Discover vm commands

```bash
az vm --help
```
