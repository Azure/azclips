# New-AzManagementGroupDeploymentWhatIf

## SYNOPSIS

Previews an ARM or Bicep deployment at management-group scope.

## SYNTAX

### __AllParameterSets

```
New-AzManagementGroupDeploymentWhatIf -ManagementGroupId <string> -Location <string>
 [-Name <string>] [-TemplateFile <string>] [-TemplateUri <string>] [-TemplateSpecId <string>]
 [-TemplateObject <hashtable>] [-QueryString <string>] [-TemplateParameterFile <string>]
 [-TemplateParameterUri <string>] [-TemplateParameterObject <hashtable>] [-ValidationLevel <string>]
 [-ResultFormat <string>] [-Profile <string>] [<CommonParameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Returns the resource changes a deployment would make at the specified management group without applying them.

## EXAMPLES

### Preview a local Bicep template

Preview a local Bicep deployment and return full before-and-after resource payloads.

```powershell
New-AzManagementGroupDeploymentWhatIf -ManagementGroupId myManagementGroup -Name myDeployment -Location eastus -TemplateFile ./main.bicep -ResultFormat FullResourcePayloads
```
