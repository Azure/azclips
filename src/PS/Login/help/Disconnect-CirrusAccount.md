# Disconnect-CirrusAccount

## SYNOPSIS

## SYNTAX

```
Disconnect-CirrusAccount [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Sign out from the current Azure account context.

## EXAMPLES
