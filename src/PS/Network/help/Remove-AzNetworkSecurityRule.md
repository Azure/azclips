# Remove-AzNetworkSecurityRule

## SYNOPSIS

Delete a security rule.

## SYNTAX

### __AllParameterSets

```
Remove-AzNetworkSecurityRule -Name <string> -NetworkSecurityGroupName <string>
 -ResourceGroupName <string> [-SubscriptionId <string>] [-Profile <string>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Deletes a security rule from a network security group.

## EXAMPLES

### Remove a security rule

```powershell
Remove-AzNetworkSecurityRule -ResourceGroupName myrg -NetworkSecurityGroupName mynsg -Name allow-https
```
