# Remove-AzVirtualNetworkSubnet

## SYNOPSIS

Delete a subnet.

## SYNTAX

### __AllParameterSets

```
Remove-AzVirtualNetworkSubnet -Name <string> -VirtualNetworkName <string>
 -ResourceGroupName <string> [-SubscriptionId <string>] [-Profile <string>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Deletes a subnet from a virtual network.
The delete fails while resources such as network interfaces still use the subnet.

## EXAMPLES

### Remove a subnet

Delete the subnet `web` from the virtual network `myvnet`.

```powershell
Remove-AzVirtualNetworkSubnet -ResourceGroupName myrg -VirtualNetworkName myvnet -Name web
```
