# Remove-AzVirtualNetworkSubnetConfig

## SYNOPSIS

Delete a subnet from a virtual network.

## SYNTAX

### __AllParameterSets

```
Remove-AzVirtualNetworkSubnetConfig -ResourceGroupName <string> -VirtualNetworkName <string> -Name <string>
 [-SubscriptionId <string>] [-Force] [-PassThru] [-Profile <string>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Deletes the named subnet from the virtual network in Azure.
The delete fails while resources such as network interfaces are still attached to the subnet, so remove them first.

## EXAMPLES

### Remove a subnet

Delete the subnet `web` from virtual network `myvnet` without prompting.

```powershell
Remove-AzVirtualNetworkSubnetConfig -ResourceGroupName myrg -VirtualNetworkName myvnet -Name web -Force
```
