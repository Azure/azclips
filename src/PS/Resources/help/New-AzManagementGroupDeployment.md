# New-AzManagementGroupDeployment

## SYNOPSIS

Creates an ARM or Bicep deployment at management-group scope.

## SYNTAX

### __AllParameterSets

```
New-AzManagementGroupDeployment -ManagementGroupId <string> -Location <string> [-Name <string>]
 [-TemplateFile <string>] [-TemplateUri <string>] [-TemplateSpecId <string>]
 [-TemplateObject <hashtable>] [-QueryString <string>] [-TemplateParameterFile <string>]
 [-TemplateParameterUri <string>] [-TemplateParameterObject <hashtable>] [-ValidationLevel <string>]
 [-DeploymentDebugLogLevel <string>] [-Tag <hashtable>] [-Profile <string>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

This cmdlet has no aliases.

## DESCRIPTION

Validates and creates a deployment at the specified management group. Supply exactly one template source. The deployment name defaults to the template file name or a timestamp.

## EXAMPLES

### Deploy a local Bicep template

Validate and deploy a local Bicep template at management-group scope.

```powershell
New-AzManagementGroupDeployment -ManagementGroupId myManagementGroup -Name myDeployment -Location eastus -TemplateFile ./main.bicep
```
