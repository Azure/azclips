# Remove-AzStorageBlob

## SYNOPSIS

Removes an Azure Storage blob, snapshot, or version.

## SYNTAX

### __AllParameterSets

```
Remove-AzStorageBlob [-BlobName] <string> -AccountName <string> -ContainerName <string>
 [-SnapshotTime <DateTimeOffset>] [-VersionId <string>] [-DeleteSnapshot] [-Force]
 [-LeaseId <string>] [-IfMatch <string>] [-IfNoneMatch <string>] [-IfModifiedSince <DateTimeOffset>]
 [-IfUnmodifiedSince <DateTimeOffset>] [-TagCondition <string>] [-PassThru] [-Profile <string>]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES


## DESCRIPTION

Removes a blob, snapshot, or version using Microsoft Entra authentication.

## EXAMPLES

### Remove a blob

Removes a blob. Use `-Force` when the blob has snapshots.

```powershell
Remove-AzStorageBlob -AccountName mystorage -ContainerName files -BlobName reports/report.csv -Force -Confirm:$false
```

### Remove a snapshot

Removes a specific blob snapshot.

```powershell
Remove-AzStorageBlob -AccountName mystorage -ContainerName files -BlobName reports/report.csv -SnapshotTime '2026-08-25T00:00:00Z' -Confirm:$false
```
